# 泰嘉网站四张材料图片路径修复包

本压缩包用于修复 304、316L、409L、430 四张材料图片无法显示的问题。

这是增量修复包：请保留 GitHub 仓库中原有的 CSS、JS、客户 Logo 和其他网站文件，不要清空仓库后只上传本包。

## 上传方法

1. 在 Windows 中先解压本 ZIP。
2. 打开 GitHub 仓库 `taijia-metal-website` 的根目录（能看到现有 `index.html` 的位置）。
3. 将解压后看到的 `index.html` 和四张图片全部上传到仓库根目录，选择替换同名文件。
4. 不要上传 ZIP 文件本身，也不要建立 `assets/material-grades` 文件夹。
5. 不要删除仓库内原有的其他文件。
6. 等待 Netlify 自动部署完成后，强制刷新网页（Windows：`Ctrl + F5`）。
