TAIJIA METAL WEBSITE — GITHUB UPLOAD GUIDE
泰嘉金属官网 — GitHub 上传说明

1. 解压本更新包。
2. 打开解压后的文件夹，确认第一层可以直接看到 index.html。
3. 在 GitHub 仓库进入 Add file > Upload files。
4. 将解压后文件夹里面的全部文件与文件夹一起拖入上传区域。
   注意：不要上传 ZIP 压缩包本身，也不要只上传 index.html。
5. 等待文件列表完成，再点击页面底部 Commit changes。
6. Netlify 会从 GitHub 自动重新部署；通常等待 1–3 分钟后刷新网站。

1. Unzip this update package.
2. Open the extracted folder and confirm index.html is visible at the first level.
3. In GitHub, choose Add file > Upload files.
4. Drag every file and folder inside the extracted folder into GitHub.
   Do not upload the ZIP itself and do not upload index.html alone.
5. Wait until the file list is complete, then click Commit changes.
6. Netlify should redeploy automatically; refresh the live site after 1–3 minutes.
